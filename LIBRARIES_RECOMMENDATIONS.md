# Приоритетные библиотеки для Budget Tracker

## 1. React Hot Toast - Уведомления

```bash
npm install react-hot-toast
```

**Зачем**: Красивые уведомления об успешных операциях, ошибках
**Применение**: Сохранение целей, операций, ошибки API

## 2. DND Kit - Drag & Drop

```bash
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

**Зачем**: Перетаскивание приоритетов целей, сортировка категорий
**Применение**: Реорганизация дашборда, изменение порядка элементов

## 3. CMDK - Командная палитра

```bash
npm install cmdk
```

**Зачем**: Быстрый поиск операций (Ctrl+K), навигация
**Применение**: Поиск по операциям, быстрое создание целей

## 4. jsPDF + html2canvas - PDF экспорт

```bash
npm install jspdf html2canvas
```

**Зачем**: Экспорт месячных отчетов, красивые документы
**Применение**: PDF отчеты, экспорт аналитики

## 5. React Big Calendar - Календарь

```bash
npm install react-big-calendar moment
```

**Зачем**: Планирование доходов/расходов, календарь операций
**Применение**: Визуализация дедлайнов, планирование бюджета

## Команда для установки всех сразу:

```bash
npm install react-hot-toast @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities cmdk jspdf html2canvas react-big-calendar moment
```
