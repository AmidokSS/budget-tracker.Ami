# Система управления целями с операциями

## Обзор изменений

Реализована полная система управления целями с автоматическим созданием операций при пополнении и снятии средств. Это обеспечивает корректное отражение движения денег в общем балансе.

## Проблема

**До изменений**: При пополнении цели деньги "исчезали" из общего баланса без создания соответствующей операции расхода. Аналогично, не было возможности снимать средства с цели.

**После изменений**:

- ✅ Пополнение цели автоматически создает операцию расхода
- ✅ Снятие средств с цели создает операцию дохода
- ✅ Общий баланс всегда корректен
- ✅ Архивированные цели скрыты из интерфейса

## Новые возможности

### 1. Автоматические операции при работе с целями

#### Пополнение цели

- **Действие**: Пользователь пополняет цель на 1000 ₽
- **Результат**:
  - Цель увеличивается на 1000 ₽
  - Создается операция расхода "Пополнение цели: [название]" на 1000 ₽
  - Общий баланс уменьшается на 1000 ₽

#### Снятие средств с цели

- **Действие**: Пользователь снимает 500 ₽ с цели
- **Результат**:
  - Цель уменьшается на 500 ₽
  - Создается операция дохода "Снятие средств с цели: [название]" на 500 ₽
  - Общий баланс увеличивается на 500 ₽

### 2. Автоматическое управление категориями

#### Категория "Цели" (расходы)

- Создается автоматически при первом пополнении цели
- Тип: `expense`
- Эмодзи: `🎯`
- Используется для всех операций пополнения целей

#### Категория "Цели (возврат)" (доходы)

- Создается автоматически при первом снятии средств
- Тип: `income`
- Эмодзи: `💰`
- Используется для всех операций снятия средств с целей

### 3. Интерфейс снятия средств

#### Новая кнопка в GoalCard

- **Иконка**: Minus (-)
- **Цвет**: Синий
- **Условие показа**: Только если в цели есть накопленные средства (currentAmount > 0)
- **Всплывающая подсказка**: "Снять средства"

#### Новый режим GoalSidebar

- **Режим**: `withdraw`
- **Заголовок**: "Снять средства"
- **Поле ввода**:
  - Ограничение: максимум = текущая сумма в цели
  - Подсказка: "Доступно для снятия: X ₽"
- **Валидация**: Проверка, что сумма не превышает накопленную

### 4. Очистка архивированных целей

#### API endpoint: `/api/goals/cleanup`

- **GET**: Автоматическая очистка (требует CRON_SECRET)
- **POST**: Ручная очистка (требует подтверждение)
- **Действие**: Удаляет все цели с флагом `archived: true`

#### Скрытие архивированных целей

- Обновлен GET `/api/goals` - возвращает только `archived: false`
- Архивированные цели не отображаются в интерфейсе

## Технические детали

### Обновленный API (`/api/goals`)

#### Новые параметры PUT запроса

```typescript
{
  id: string,
  addAmount?: number,      // Пополнение цели
  withdrawAmount?: number, // Снятие средств
  userId?: string         // ID пользователя (по умолчанию '1')
}
```

#### Логика транзакций

1. **Пополнение** (`addAmount`):

   ```typescript
   // 1. Проверка существования цели
   // 2. Валидация суммы (> 0)
   // 3. Обновление цели
   // 4. Создание/поиск категории "Цели"
   // 5. Создание операции расхода
   ```

2. **Снятие** (`withdrawAmount`):
   ```typescript
   // 1. Проверка существования цели
   // 2. Валидация суммы (> 0 и <= currentAmount)
   // 3. Обновление цели
   // 4. Создание/поиск категории "Цели (возврат)"
   // 5. Создание операции дохода
   ```

### Обновленные React хуки

#### Новый хук: `useWithdrawFromGoal`

```typescript
export const useWithdrawFromGoal = () => {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: api.withdrawFromGoal,
    onSuccess: () => {
      // Обновляем все связанные данные
      queryClient.invalidateQueries({ queryKey: ['goals'] })
      queryClient.invalidateQueries({ queryKey: ['operations'] })
      queryClient.invalidateQueries({ queryKey: ['statistics'] })
      queryClient.invalidateQueries({ queryKey: ['usersStatistics'] })
      queryClient.invalidateQueries({ queryKey: ['summary'] })
    },
  })
}
```

## Примеры использования

### Пополнение цели

```typescript
// Пользователь пополняет цель "Отпуск" на 5000 ₽
await api.addToGoal({ id: 'goal-123', addAmount: 5000 })

// Результат:
// 1. goal.currentAmount += 5000
// 2. Создана операция расхода в категории "Цели" на 5000 ₽
// 3. Общий баланс -= 5000
```

### Снятие средств

```typescript
// Пользователь снимает 2000 ₽ с цели "Отпуск"
await api.withdrawFromGoal({ id: 'goal-123', withdrawAmount: 2000 })

// Результат:
// 1. goal.currentAmount -= 2000
// 2. Создана операция дохода в категории "Цели (возврат)" на 2000 ₽
// 3. Общий баланс += 2000
```

### Очистка архива

```bash
# Ручная очистка через API
curl -X POST http://localhost:3000/api/goals/cleanup \
  -H "Content-Type: application/json" \
  -d '{"secret": "your-secret", "confirm": true}'
```
