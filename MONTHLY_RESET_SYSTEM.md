# Система месячного сброса для Budget Tracker

## Обзор

Реализована система месячного сброса операций с сохранением баланса для трекера бюджета. Система позволяет автоматически "архивировать" доходы и расходы каждого месяца, при этом общий баланс переносится в следующий период.

## Новые компоненты

### 1. MonthlyDashboard (`src/components/MonthlyDashboard.tsx`)

- **Назначение**: Интерактивный dashboard для отображения месячной статистики на главной странице
- **Основные функции**:
  - Отображение текущего месячного баланса
  - Показ доходов и расходов за текущий месяц
  - История предыдущих периодов
  - Предпросмотр месячного сброса
  - Анимированные карточки с статистикой
- **Интеграция**: Добавлен на главную страницу с lazy loading

### 2. Monthly Stats API (`src/app/api/monthly-stats/route.ts`)

- **Назначение**: API для получения месячной статистики без изменения схемы БД
- **Endpoints**:
  - `GET /api/monthly-stats` - получение статистики по месяцам
  - `POST /api/monthly-stats/simulate-reset` - симуляция сброса для демонстрации
- **Функции**:
  - Группировка операций по месяцам
  - Расчет накопительного баланса
  - Статистика текущего месяца

### 3. Monthly Reset Cron Job (`src/app/api/cron/monthly-reset/route.ts`)

- **Назначение**: Автоматический месячный сброс (временная версия)
- **Механизм**: Использует пометки в заметках операций вместо изменения схемы БД
- **Функции**:
  - Создание маркеров архивирования
  - Пометка операций как архивированных
  - Расчет баланса периода
  - Создание записи-маркера для отслеживания сброса

### 4. Monthly Balance Utils (`src/lib/monthlyBalanceUtils.ts`)

- **Назначение**: Утилиты для работы с месячными периодами
- **Функции**:
  - Определение текущего периода
  - Расчет месячного баланса
  - Проверка необходимости сброса
  - Форматирование периодов
  - Статистика по периодам

## Принцип работы

### Месячный сброс

1. **Определение периода**: Система определяет текущий месяц в формате "YYYY-MM"
2. **Проверка сброса**: Проверяется, был ли уже выполнен сброс для данного периода
3. **Группировка операций**: Операции текущего месяца группируются и анализируются
4. **Расчет баланса**: Вычисляется итоговый баланс (доходы - расходы)
5. **Архивирование**: Операции помечаются специальными маркерами в заметках
6. **Создание маркера**: Создается специальная операция-маркер с информацией о периоде

### Отображение статистики

1. **Текущий месяц**: Показываются активные операции без архивных маркеров
2. **История периодов**: Отображается статистика предыдущих месяцев
3. **Накопительный баланс**: Общий баланс учитывает все периоды
4. **Визуализация**: Анимированные компоненты с градиентами и эффектами
